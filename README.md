# CareerLens AI

## AI-Powered Resume Analysis & Career Intelligence

CareerLens AI analyzes PDF and DOCX resumes and provides an ATS-style score, skill detection, structure analysis, job keyword matching, strengths, improvement areas and personalized recommendations.

### Features
- PDF and DOCX resume parsing
- ATS-style resume scoring
- Resume structure detection
- Skills categorization
- Job description keyword matching
- Missing keyword intelligence
- Personalized recommendations
- Target company and role context
- Responsive modern UI
- No database required

### Run Locally
```bash
pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000`

### Disclaimer
This project provides educational ATS-style guidance and does not predict actual hiring outcomes.
